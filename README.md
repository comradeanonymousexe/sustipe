# IPE Batch '31 — Optima · SUST

Ultra-premium one-page showcase for the Industrial & Production Engineering department, Batch '31, Shahjalal University of Science & Technology.

## Deploy to GitHub Pages

1. Create a new repository on GitHub
2. Push all files:
   ```bash
   git init
   git add .
   git commit -m "IPE Batch 31 — Optima"
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
3. Go to **Settings → Pages → Source → main branch → Save**
4. Site live at: `https://YOUR_USERNAME.github.io/YOUR_REPO/`

## File Structure
```
├── index.html       — One-page HTML structure
├── css/style.css    — All styles (dark cinematic theme)
├── js/script.js     — Preloader, 3D gear, cursor, parallax, tilt, roster
├── assets/banner.png — Banner image
└── .nojekyll        — Required for GitHub Pages
```
